3. You don't have to write fixtures by hand. Record mode proxies the real API, saves each response as a fixture and replays it deterministically after that. Run the CLI with --record and --provider-openai pointing at the real OpenAI endpoint, use your app as normal, then commit the fixtures folder. Auth headers are never saved, but prompts and responses are, so review them first. In CI, turn on strict mode: any unmatched request gets a 503 instead of reaching a paid API. Strict mode wins over record mode.

2. claude-slim by iops-leo is an open-source CLI and Claude Code plugin that audits that startup context. It reads ~/.claude/, measures what each skill, plugin, agent, MCP server and memory file costs with js-tiktoken, then moves the dead weight aside so you can bring it back. No proxy, no compression, no change to how Claude Code talks to the API. MIT license, 43 stars, latest release v2.16.2 on 2026-11-01.

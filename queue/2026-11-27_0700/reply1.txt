1. Testing one app across devices, languages and text sizes by hand is slow. Scripted tests only check what someone wrote down. pierridotite/mobile-agent-testers (MIT, 2511 stars) runs Claude Code agents as exploratory testers instead. Each agent gets its own iOS Simulator or Android emulator on GitHub Actions, with no test scripts. A run can use up to about 20 phones in parallel. Android runs on Linux runners and iOS on macOS runners.

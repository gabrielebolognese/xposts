1. Every file read, command result and fetched page lands in your agent's context window. Long sessions burn tokens and hit compaction early. Context Mode is a local plugin for 11 coding agents, including Claude Code, Codex, Gemini CLI and Copilot CLI. It keeps big tool output out of the context. The full output goes into a SQLite FTS5 index on your machine, and the agent gets back only the part it asks for.

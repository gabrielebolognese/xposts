3. Beyond the defaults there are 50+ optional packs for databases, Kubernetes, Docker, AWS/GCP/Azure and Terraform. Most are off. Turn them on in dcg's config file:

"database.postgresql" blocks DROP TABLE, TRUNCATE
"kubernetes.kubectl" blocks kubectl delete namespace
"cloud.aws" blocks aws ec2 terminate-instances

To see why a command was blocked, run dcg explain "command". There's also a scan mode for pre-commit hooks and CI that catches dangerous commands in code review.

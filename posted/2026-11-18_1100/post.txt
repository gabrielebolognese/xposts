Claude Opus 5.5 built a heart that stops and restarts, cell by cell on a GPU, in 271 minutes

What it simulates, how it was built, the real numbers, where it was hard, and how to try this tonight.

1. A slice of a human heart after a heart attack, simulated cell by cell on a 512 x 512 grid. Each cell runs Aliev-Panfilov excitable media, coupled to an event-driven Purkinje tree. One premature beat at the scar border starts a spiral wave around the scar: ventricular tachycardia. A shock ends it. The 12-lead ECG is computed live from the tissue's own currents.

2. Built by Claude Opus 5.5 in Claude Code, alone, at effort xhigh. 271 minutes of work, 387 turns, 5251 lines of code. Build cost: $174.17. No libraries: raw WebGL2, canvas 2D and one Web Worker. A separate critic reviewed it over 2 rounds and gave the final version 8.3 out of 10.

3. Sinus rhythm at 72 bpm, PR 190 ms, QRS 101 ms, QTc 306 ms. A premature beat 320 ms after the last sinus activation sets off VT at 138 bpm, QRS over 200 ms, with 2 spiral tips at peak. From shock to first sinus beat: 1038 ms of sim time. On an AMD Ryzen 7 5700U with integrated Radeon graphics the solver used 5.85 ms of GPU time per frame, 121,889,196 cell updates per second. GPU load averaged 24.3%.

4. The arrhythmia can't be faked. The tissue had to be tuned so a real premature beat in the vulnerable window causes one-way block around the scar, and a real field shock ends it. To fit an integrated GPU it skips everything but the 23,754 excitable cells out of 262,144. It even built a backup S2 and a second shock. Neither was ever needed.

5. To try it tonight: pick a system whose behavior can't be faked. Tell Claude Code to write it without libraries, log every event exactly as delivered, and compute the headline numbers from its own output instead of hardcoding them. Run a separate critic session to review and score it, feed the critique back, repeat. Set effort to xhigh and let it run for hours.

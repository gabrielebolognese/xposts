7. Setup. Go to GitHub and search for: pierridotite/mobile-agent-testers. Or search the web for: mobile-agent-testers Claude Code.
You need a GitHub account, the gh CLI, and a Claude subscription or an Anthropic-compatible API key. No Mac needed.
1. gh repo create my-testers --public --template pierridotite/mobile-agent-testers --clone
2. cd my-testers && ./setup.sh (it stores a Claude token and secrets in your repo, so read it first)
3. gh workflow run agent-testers.yml
4. bash scripts/collect.sh <run id> to decrypt the reports and write SUMMARY.md
Want Claude to set it up for you? Run /plugin marketplace add pierridotite/mobile-agent-testers, then /plugin install mobile-agent-testers@mobile-agent-testers.
On a plan with a usage limit, start with a batch of 6-10 phones. Use test accounts, never real ones.

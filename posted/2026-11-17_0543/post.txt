What it simulates, how it was built, the real numbers, where it struggled, and how to push Claude Code like this.

1. A chess engine written from scratch in plain JS replays Byrne vs Fischer, New York 1956, the Game of the Century, and reviews it move by move. Its search is split across 8 Web Workers that share no memory. Everything it thinks is drawn live: the search tree, pruning, the hash table, move ordering and the threads.

2. Claude Opus 5.5 built it alone in Claude Code at effort xhigh: 220 minutes, 270 turns, 4166 lines of code. No libraries, no images, no glyph fonts. Even the pieces are vector paths drawn by hand. Build cost: $113.65 at API prices. A separate critic reviewed it in 2 rounds. Final score 8.9 out of 10.

3. Live run on an AMD Ryzen 7 5700U (8 cores, 16 threads) with integrated Radeon graphics. 577,254,980 positions searched, peak 7,209,287 nodes per second across 8 workers, depth 17, selective depth 37. It locked in Fischer's 17...Be6 at depth 5 and scored it 111 centipawns for Black. 89.6% of cutoffs came from the first move tried. The page ran at 19 to 60 fps.

4. A pure root split left workers idle, because this game is full of checks with 3 to 7 legal moves. In forced spots like 18...Bxc4+ and 19...Ne2+, five of eight workers sat idle. Opus split the main line one level deeper and let idle workers start later depths early. One simplification: when a scout and its re-search keep disagreeing, it takes the latest score as exact.

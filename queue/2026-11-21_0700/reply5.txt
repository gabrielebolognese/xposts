5. Caveats worth knowing. It is self-hosted, so you run and maintain the server. Native Windows is experimental. Linux, macOS and Windows via WSL2 are supported. The site itself warns that credential redaction can miss sensitive text, so review what gets stored, especially on a shared server. The LLM 'dream' consolidation is off by default and keeps the pre-merge versions. Still very active: v3.5.1 shipped on 2026-11-19.

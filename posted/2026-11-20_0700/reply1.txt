1. Agents burn context on tool output: logs, JSON arrays, search results. Headroom (headroomlabs-ai/headroom, about 80k stars) compresses that output before it reaches the model. It sends each content type to its own compressor: SmartCrusher for JSON, CodeCompressor (AST) for source code, Kompress-v2-base for prose. All of it runs on your machine. No prompt or file content is sent anywhere to be compressed.

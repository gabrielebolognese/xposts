7. How to get it running:

Go to GitHub and search for: reticlehq/reticle
Or search the web for: Reticle coding agent verification MCP

1. Install Node 20.11+ and start your web app's dev server.
2. In the app folder run: npx @reticlehq/server
3. Read the result: verified: yes or verified: no.
4. To give your coding agent the tool, run: npx @reticlehq/server init
5. Open Claude Code, Cursor or any MCP agent and ask it to check its change with Reticle before it says done.
6. Optional: set DO_NOT_TRACK=1 to turn off the usage counts.

Use the scoped package. Don't run npx reticle, it fetches an unrelated package.

6. Setup:
Go to GitHub and search for: DeusData/codebase-memory-mcp. Or do a web search for codebase-memory-mcp.

1. macOS/Linux: copy the one-line curl install command from the README quick start and run it.
2. Windows: download install.ps1 as the README shows, read it first, then run it. SmartScreen may warn you.
3. Prefer a package manager? It is also on npm, PyPI, Homebrew, Scoop, AUR and go install. Use v0.12.1 or newer, which fixed the install paths that broke in v0.12.0.
4. In the installer, pick your agents. It covers 46 client integrations, Claude Code and Codex among them.
5. Restart your agent and ask it to index this project.
6. Before the agent starts grepping, ask it structural questions like who calls this function or what this change affects.

6. How to set it up:
1. Go to GitHub and search for: vshulcz/deja-vu (or search the web for: deja-vu vshulcz coding agent memory). Latest release is v0.24.2.
2. One-step install that also wires your installed agents (needs Node):
npx @vshulcz/deja-vu install --auto
3. On Windows you can also use:
scoop install deja-vu
or
winget install vshulcz.deja-vu
4. Prefer a Claude Code plugin? Run:
claude plugin marketplace add vshulcz/deja-vu
then
claude plugin install deja-vu@deja-vu
5. When an agent wipes uncommitted work, run restore with the file path, for example:
deja restore internal/auth/jwt.go
6. To move the current session to Codex:
deja handoff --to codex

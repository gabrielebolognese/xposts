Claude Opus 5.5 simulated a full nuclear reactor core in the browser. 183 minutes, $77.47.

What it simulates, how it was built, the real numbers, where it struggled, and how to push Claude Code the same way.

1. A full 3411 MWt pressurized-water reactor core, solved live as two-group neutron diffusion on 18,496 cells. It tracks iodine-xenon poisoning, fuel and moderator temperature feedback, and automatic rods and boron. The core runs a night of grid load-follow, then a control rod drops. Six Web Workers run Monte Carlo transport as an independent check.

2. Built by Claude Opus 5.5 in Claude Code, alone, effort xhigh. 183 minutes over 210 turns, $77.47 at API prices, 3990 lines of code, no libraries. Hand-written WebGL draws the heatmaps. A separate critic ran 2 review rounds; final score 8.6 out of 10.

3. At boot it solves the IAEA 2D PWR benchmark: k = 1.02943 vs the reference 1.02959, a 15.3 pcm gap. Monte Carlo lands within 55 pcm of diffusion (0.99955 ± 184 pcm) after 52,640,000 histories. Xenon pit after the 100 to 50% ramp: -5407 pcm. The dropped rod drives quadrant tilt to 1.5111 against a 1.02 limit. Live on a Ryzen 7 5700U with Radeon graphics: 45 to 60 fps.

4. Three timescales on one screen: neutron generations in microseconds, rod kinetics in seconds, xenon over hours. All of it hangs on one eigenvalue solver that has to be right, not just plausible. Where it simplified: the controller is quasi-static, xenon is integrated with flux held constant per step, and the core is 2D with a fixed axial buckling, not full 3D.

AI coding agents sometimes run git reset --hard, rm -rf ./src or DROP TABLE users and wipe hours of uncommitted work in seconds. dcg (Destructive Command Guard) is a Rust hook that checks every shell command before the agent runs it. It works from rules, so it doesn't depend on the model behaving. It supports Claude Code, Codex CLI, Gemini CLI, Copilot CLI, Cursor and more. It has about 6.4k stars, and the latest release is v0.16.0 from 2026-11-01.

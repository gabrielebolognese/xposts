4. Building your own app instead? The Python library runs in-process, with no API key and no model download:

from headroom import compress
result = compress(messages, model="gpt-4o")

It takes OpenAI or Anthropic message dicts. The README claims 60-95% fewer tokens on JSON. Compression is reversible: originals stay cached locally, and the MCP tool headroom_retrieve lets the model pull the full text back. headroom_compress and headroom_stats work in any MCP client.

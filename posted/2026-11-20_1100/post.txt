Claude Opus 5.5 built a RISC-V CPU from 14,000 gates in 126 minutes. Here it paints a Mandelbrot.

What it simulates, how it was built, the real numbers, where it struggled, and how to push Claude Code the same way.

1. This is a 5-stage pipelined RISC-V core (RV32I plus MUL/MULH) built only from 2-input logic gates and flip-flops. Every gate is simulated on every clock cycle while the core runs a real fixed-point Mandelbrot program. A golden ISA model checks each retired instruction in lockstep, and 6 workers break gates on purpose to measure stuck-at fault coverage.

2. Built by Claude Opus 5.5 in Claude Code, alone, no libraries, effort xhigh. 126 minutes of work over 207 turns, 3486 lines of code, build cost $77.37. A separate critic reviewed it in 2 rounds, final score 8.7 out of 10. It also wrote the RV32 assembler and the Mandelbrot program in assembly.

3. 12,440 logic cells plus 1,560 DFFs (29,812 NAND2-eq), all simulated every cycle. The core ran at 24,000 cycles per second, 298,560,000 gate evaluations per second. 2,146,340 instructions retired, 0 lockstep divergences. IPC 0.955, branch accuracy 98.5%, fault coverage 82.2%. Page at 39 to 60 fps on a Ryzen 7 5700U laptop, 24.5% average CPU.

4. Every bit has to be right: one wrong gate and the Mandelbrot corrupts. The multiplier is a Baugh-Wooley array with a Dadda tree of 900 full adders, and the critical path runs 49 levels through it. Simplifications: ROM and RAM are behavioral arrays at the netlist ports, not gates. Toggle counting in plain JS was too slow, so it hand-assembled a WebAssembly SIMD function.

Ask for exact counts, not estimates. Name the real techniques you expect, like Kogge-Stone adders or a Dadda tree. Then run a separate critic and feed its notes back.

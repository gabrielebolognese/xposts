1. Coding agents write UI code and say done, but they can't confirm what it does at runtime. Failed requests and console errors rarely show up in a code review. Reticle is an open-source SDK, CLI and MCP server that drives your real running app. It reads network calls, console output, app state and the source line behind each element. Then it returns pass, fail or cannot tell, with the file:line to fix. About 1.3k stars on GitHub.

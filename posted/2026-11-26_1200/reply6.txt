6. Mini setup guide:
Go to GitHub and search for: pbakaus/impeccable
Or search the web for: Impeccable design skill by Paul Bakaus

1. In your project root, run: npx impeccable install
2. Reload your coding tool. It supports 19 agents, including Claude Code, Cursor, Codex CLI and GitHub Copilot.
3. Run /impeccable init in your agent ($impeccable init on Codex). It writes PRODUCT.md.
4. Start narrow. It's strongest on pages that already exist, so point one command at one target: /impeccable bolder the pricing cards
5. Optional CI check: npx impeccable detect --sarif src/

Node is only needed for npx. The license is Apache-2.0, so commercial use is allowed if you keep the license and attribution notices.

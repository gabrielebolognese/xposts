Project: Every Gate: A RISC-V Core Paints a Mandelbrot: Claude designs a 5-stage pipelined RISC-V CPU (RV32I plus MUL/MULH) entirely out of 2-input logic gates and flip-flops, then simulates every gate on every clock cycle while the core runs a real fixed-point Mandelbrot program. A golden ISA model checks each retired instruction in lockstep, and 6 workers deliberately break gates to measure stuck-at fault coverage.
Why it is hard: Claude has to write the hardware itself, as a netlist generated by small HDL-style JS functions, and every bit has to be right. If one gate is wrong anywhere, the Mandelbrot visibly corrupts and the lockstep checker flags it. The core needs Kogge–Stone adders, a 5-level barrel shifter, a Baugh–Wooley signed multiplier with a Dadda reduction tree, a 31×32 flip-flop register file with 32:1 mux read trees, an immediate generator, byte-lane load/store logic, forwarding, load-use stall detection, BTFN branch prediction and flush logic, all from AND/OR/XOR/NOT/NAND/NOR/MUX primitives. The netlist must be levelized and compiled into straight-line JS that runs tens of millions of gate evaluations per second. Claude also has to write an RV32 assembler and the Mandelbrot program in assembly, run the ISA golden model in lockstep, and build bit-parallel fault simulation (31 faulty machines per 32-bit word) across Web Workers. On top of that, a WebGL floorplan draws every gate as a cell that lights when it switches. The layers depend on each other: none of it can be faked, and if one layer is broken, everything above it breaks too.
The science: 1) NETLIST. Primitives: NOT, AND2, OR2, NAND2, NOR2, XOR2, XNOR2, MUX2 (counted as 1 cell, NAND2-equivalent weights INV 0.67, NAND/NOR 1, AND/OR 1.33, XOR/XNOR 2, MUX2 2.33) and DFF (positive edge; enable and synchronous reset built from a MUX2 in front). Generators in JS (wire(), gate(), bus(n), adderKS(n), mux(n), decoder(k), reg(n,en,rst)) produce arrays type[], inA[], inB[], inS[] plus a module tag per net. Blocks:
- IF: PC register (32 DFF), PC+4 incrementer, next-PC mux {PC+4, ID-predicted target, EX-redirect target}.
- IF/ID register.
- ID: full RV32I+MUL/MULH decoder (opcode/funct3/funct7 to control bits); immediate generator for I/S/B/U/J; register file of 31×32 DFFs (x0 hardwired to 0), a 5→32 write decoder, and two read ports built as 32:1 trees of MUX2, with a WB→ID internal bypass. Hazard unit: stall if ID/EX.memRead && ID/EX.rd≠0 && (rd==rs1 || rd==rs2), which freezes PC and IF/ID and inserts a bubble into ID/EX. Branch prediction is BTFN: for B-type with imm[31]=1, predict taken and redirect from ID with a dedicated target adder (1 bubble). JAL is redirected in ID.
- ID/EX register.
- EX: forwarding muxes A/B (select EX/MEM.rd match first, then MEM/WB.rd match, rd≠0, gated by the FORWARDING control input; when it is off, the hazard unit stalls on any RAW instead). ALU: 32-bit Kogge–Stone add/sub (5 prefix levels), SLT/SLTU from the carry and sign, AND/OR/XOR, and a 5-stage logarithmic barrel shifter (SLL by bit-reversal; SRA via sign fill). Multiplier: 32×32 Ba

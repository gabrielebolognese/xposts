5. It's free and open source under Apache-2.0, but know the catches. Google collects usage statistics by default: add --no-usage-statistics to the args. Performance tools may send trace URLs to Google's CrUX API to fetch real-user data, and the README lists the flag to turn that off. The agent can inspect and modify any data in that browser, so use the isolated option and keep it off logged-in sensitive sites. Officially it supports only Google Chrome and Chrome for Testing.

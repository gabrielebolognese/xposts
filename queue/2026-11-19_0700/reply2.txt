2. It blocks dangerous git and filesystem commands out of the box, with no config. A block looks like this:

Reason: git reset --hard destroys uncommitted changes ... Tip: Consider using 'git stash' first to save your changes.

It reads what a command does, not just its text. grep "rm -rf" runs, rm -rf / gets blocked. It also catches python -c "os.remove(...)" and scripts inside heredocs. On native Windows, 2 extra packs are on by default and block del /s, rd /s and format.

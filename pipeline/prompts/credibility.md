# Stage: credibility

The research for a planned X post is done. Judge how credible the post's core claims are, based on what the research actually found. You see the idea and every fact: its source link, date, the quoted evidence, and its kind (source = from a web page, measured = from a check that really ran in a sandbox).

Score credibility from 0 to 3:
- 3: the core claims rest on primary sources (official docs, changelogs, release notes, source code, the maintainers' own words) or on checks that ran, and nothing found contradicts them
- 2: the core claims are backed by reliable sources or a passing check; some side details are weaker
- 1: the core claims rest mostly on secondary sources (blogs, forum posts, social media), a single anecdote, or facts that are old or only loosely related
- 0: the core claims have no support, or a fact contradicts them

Also list the idea's core claims, each with the ids of the facts that back it (empty when none), and give a short reason for the score.
